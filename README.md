# سامانه مدرسه هوشمند

پروژه‌ی قابل اجرا با Node.js، Express و SQLite؛ رابط فارسی و راست‌چین و واکنش‌گرا.

## اجرا
1. Node.js نسخه 18 یا جدیدتر نصب باشد.
2. در پوشه پروژه اجرا کنید:
   ```bash
   npm install
   ```
3. فایل `.env.example` را به `.env` کپی کنید و `JWT_SECRET` را با یک مقدار طولانی و تصادفی جایگزین کنید.
4. اجرا:
   ```bash
   npm start
   ```
5. مرورگر: `http://localhost:3000`

## حساب‌های آزمایشی اولیه
- مدیر: `admin` / `Admin12345!`
- معلم: `teacher` / `Teacher123!`
- دانش‌آموز: `student` / `Student123!`

این حساب‌ها فقط در اولین راه‌اندازی پایگاه داده خالی ساخته می‌شوند. برای استفاده واقعی رمزهای پیش‌فرض را عوض کنید و حساب‌های آزمایشی را حذف کنید.

## دستیار هوشمند
برای فعال‌سازی، `AI_API_KEY` را در `.env` قرار دهید. کلید فقط روی سرور نگهداری می‌شود و نباید در فایل‌های فرانت‌اند قرار گیرد. `AI_MODEL` قابل تغییر است. دسترسی سرور به سرویس مدل نیز لازم است.

## امکانات پیاده‌سازی‌شده
- ورود امن با هش رمز عبور، کوکی HttpOnly و نقش‌های دانش‌آموز، معلم، معاون و مدیر
- ثبت‌نام دانش‌آموز با جلوگیری از نام کاربری تکراری
- داشبورد و اطلاعیه‌ها
- تعریف تکلیف و ارسال پاسخ دانش‌آموز
- ثبت نمره و نمایش کارنامه دانش‌آموز
- ثبت حضور و غیاب از API
- مدیریت کاربران و گزارش نمرات
- دستیار هوش مصنوعی قابل اتصال از سمت سرور
- پوسته روشن/تاریک و PWA پایه

## پیش از بهره‌برداری واقعی
این نسخه یک پایه‌ی اجرایی است، نه سامانه‌ی آماده‌ی استقرار عمومی برای داده‌های حساس دانش‌آموزان. برای انتشار عمومی باید HTTPS، محدودسازی تلاش ورود، CSRF protection، اعتبارسنجی و ثبت رویدادهای مدیریتی، سیاست پشتیبان‌گیری و بازیابی، مدیریت نشست و آزمون امنیتی مستقل اضافه شود. همچنین نام مدرسه، لوگو، کلاس‌ها و فرآیندهای رسمی مدرسه باید پیکربندی شوند. SQLite برای شروع و مدرسه کوچک مناسب است؛ برای مقیاس بالاتر PostgreSQL توصیه می‌شود.
